# Changelog

## 0.1.0 (2026-10-26)

- First release: seven browser tools (`puppeteer_navigate`,
  `puppeteer_screenshot`, `puppeteer_click`, `puppeteer_hover`,
  `puppeteer_fill`, `puppeteer_select`, `puppeteer_evaluate`) over
  an injectable browser executor, with the dangerous-launch-options
  guard, screenshot bookkeeping and a console-log buffer.
- One bin serves the CLI and a stdio MCP server (`mcp` subcommand).
